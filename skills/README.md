## ⚙️ Environment Configuration

Set your shell variables to point to your local 9Router instance:

```bash
export NINEROUTER_URL="http://localhost:20128"   # or port 20129 if running parallel
export NINEROUTER_KEY="sk-9router"               # from Dashboard → Endpoint & Key
```

Test connectivity:
```bash
curl -s http://localhost:20128/api/health
# {"engine":"native-rust","headroom":"integrated","status":"ok","version":"0.0.22"}
```
